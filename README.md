# Atom Lab

ห้องทดลองธาตุและอะตอมเชิงโต้ตอบ — ตารางธาตุ 118 ธาตุ เครื่องสร้างอะตอม ห้องผสมธาตุ และแบบทดสอบ
รวมอยู่ในไฟล์เดียว เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต

--------------------------------------------------------------------------------

## เริ่มใช้งาน

1. กดปุ่ม `Releases` ด้านขวา → `Download ZIP`
2. แตกไฟล์ ZIP
3. เข้าโฟลเดอร์ `dist` แล้วเปิด `Atom Lab.html`

**เท่านั้นครับ โปรแกรมจะเปิดในเบราว์เซอร์ทันที**
> **อยากเปิดแบบหน้าต่างโปรแกรม** ให้คลิก `เปิด Atom Lab.cmd`
> ต้องวางไว้โฟลเดอร์เดียวกับ `Atom Lab.html` — ใช้ได้เฉพาะ Windows ที่มี Chrome หรือ Edge

--------------------------------------------------------------------------------

###### มีอะไรบ้าง #######

### ⚛️ ตารางธาตุ
ธาตุครบทั้ง 118 ตัว แบ่งสีตามหมวด ชี้เมาส์เพื่อดูรายละเอียด — มวลอะตอม จุดหลอมเหลว จุดเดือด
ความหนาแน่น อิเล็กโทรเนกาติวิตี การจัดเรียงอิเล็กตรอน ปีที่ค้นพบ พร้อมคำอธิบายภาษาไทยทุกธาตุ
ค้นหาได้ด้วยชื่อไทย ชื่ออังกฤษ สัญลักษณ์ หรือเลขอะตอม

### 🔬 สร้างอะตอม
ปรับจำนวนโปรตอน นิวตรอน อิเล็กตรอนเอง แล้วดูว่าได้ธาตุอะไร เป็นไอออนหรือไอโซโทปแบบไหน
พร้อมภาพอะตอม 3 มิติที่หมุนได้ และการจัดเรียงอิเล็กตรอนตามหลักเอาฟ์เบา

### 🧪 ผสมธาตุ
เลือกธาตุมาผสมกัน แล้วระบบจะวิเคราะห์ให้ว่า

- เขียนเป็นสูตรเคมีได้อย่างไร (รวมถึงไอออนเชิงซ้อนอย่าง `Al₂(SO₄)₃`)
- เกิดพันธะชนิดไหน — ไอออนิก โคเวเลนต์มีขั้ว/ไม่มีขั้ว หรือพันธะโลหะ
- เลขออกซิเดชันของแต่ละธาตุ พร้อมวิธีตรวจว่าประจุรวมเป็นศูนย์
- รูปร่างโมเลกุลตามทฤษฎี VSEPR พร้อมแบบจำลอง 3 มิติ
- บัญชีอิเล็กตรอนว่าอะตอมไหนให้ รับ หรือใช้ร่วมกันกี่ตัว

### 📝 แบบทดสอบ
ออกข้อสอบอัตโนมัติจากข้อมูลธาตุจริง เลือกหัวข้อและจำนวนข้อได้ มีเฉลยพร้อมคำอธิบาย

## ต้องใช้อะไรบ้าง
|---|---|
| **เบราว์เซอร์** | Chrome, Edge, Firefox หรือ Safari รุ่นใหม่ ๆ |
| **อินเทอร์เน็ต** | ไม่จำเป็น — ใช้งานออฟไลน์ได้ทุกฟีเจอร์ (ต่อเน็ตแค่ทำให้ฟอนต์สวยขึ้น) |
| **การติดตั้ง** | ไม่ต้อง |

ใช้บนมือถือและแท็บเล็ตได้เช่นกัน

--------------------------------------------------------------------------------

## เจอข้อมูลผิดหรือโปรแกรมมีปัญหา

กดปุ่ม **แจ้งปัญหา** มุมขวาล่างของโปรแกรม ระบบจะแนบสถานะหน้าจอ
ไปให้อัตโนมัติ ช่วยให้ตามหาสาเหตุได้เร็วขึ้นมาก

--------------------------------------------------------------------------------

## หมายเหตุ

ข้อมูลธาตุอ้างอิงตารางธาตุ IUPAC · สร้างด้วย HTML + CSS + JavaScript ล้วน ไม่ใช้ไลบรารีภายนอก
ไฟล์ใน `dist/` เป็นเวอร์ชันที่รวมและย่อโค้ดแล้ว ซอร์สโค้ดไม่ได้เผยแพร่ใน repo นี้
